# Kun 内置工具完整清单

## 一、工具注册架构

所有工具通过 `LocalToolHost.defineTool()` 定义，按 **Provider（提供者）** 分类注册到 `CapabilityRegistry`。

```typescript
// 工具定义类型 (kun/src/adapters/tool/local-tool-host.ts:39-49)
type LocalTool = {
  name: string
  description: string
  inputSchema: Record<string, unknown>
  toolKind: 'tool_call' | 'command_execution' | 'file_change'
  policy: 'auto' | 'on-request' | 'suggest' | 'never' | 'untrusted'
  shouldAdvertise?: (context: ToolHostContext) => boolean
  execute: (args, context, onUpdate?) => Promise<{ output, isError? }>
}
```

## 十二、MCP Provider — 动态

源文件：`kun/src/adapters/tool/mcp-tool-provider.ts`

- 工具名和数量完全由所连 MCP 服务器的 `tools/list` 响应决定
- 支持 `stdio`、`sse`、`streamable-http` 三种传输方式
- 审批策略从 MCP tool annotations 中派生
- 工具发现模式：`direct`（直接列出）/ `search`（BM25 检索入口）/ `auto`
