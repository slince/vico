# 员工管理手册

## 考勤制度

1. 标准工作时间：周一至周五，9:00 - 18:00
2. 午休时间：12:00 - 13:00
3. 迟到30分钟以内记为迟到，30分钟以上记为旷工半天
4. 加班需提前申请，经部门主管审批

## 请假类型

1. 年假：工作满1年后享受5天带薪年假，逐年递增
2. 病假：凭医院证明，带薪病假每年不超过12天
3. 事假：按日扣除工资，每年累计不超过20天
4. 婚假：3天，需提供结婚证明
5. 产假：98天，含产前15天
6. 丧假：1-3天，直系亲属

## 员工福利

1. 五险一金：按国家规定缴纳
2. 餐补：工作日20元/天
3. 交通补贴：200元/月
4. 通讯补贴：100元/月
5. 年终奖：根据绩效考核发放
